# Vexora Client Website

## Dateien

- `index.html` – Startseite
- `style.css` – Design
- `script.js` – kleine Animationen
- `Vexora-Client-Setup.exe` – hier deinen fertigen Inno-Setup-Installer hineinlegen

## Wichtig für den Download

Lege deine fertige Datei exakt unter diesem Namen in denselben Ordner wie `index.html`:

`Vexora-Client-Setup.exe`

Der Download-Button ist bereits darauf eingestellt.

## Veröffentlichung mit GitHub Pages

1. Erstelle ein GitHub-Repository.
2. Lade `index.html`, `style.css`, `script.js` und `Vexora-Client-Setup.exe` hoch.
3. Öffne im Repository `Settings` → `Pages`.
4. Wähle als Quelle den Branch `main` und den Ordner `/ (root)`.
5. Speichern. GitHub zeigt dir danach die Website-Adresse an.

## Anpassungen

Suche in `index.html` nach:
- `Version 1.0.0`
- `© 2026 Vexora Client`
- FAQ-Texten

Wenn du einen Discord-Link hast, kann ein Button dafür ergänzt werden.
