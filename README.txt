VEXORA CLIENT – GITHUB PAGES

Dateien:
- index.html
- style.css
- script.js

UPLOAD:
Lade diese drei Dateien direkt in das Hauptverzeichnis deines GitHub-Pages-Repositories hoch.

DOWNLOAD:
Der Download-Button zeigt auf:
https://github.com/vexoraclient/vexoraclient.github.io/releases/latest/download/Vexora-Client-Setup.exe

WICHTIG:
Erstelle auf GitHub ein Release und lade dort die Datei
Vexora-Client-Setup.exe als Release-Asset hoch.

Danach lädt der Button automatisch das Asset aus dem neuesten Release.
